# WebShield — Security Testing Lab

A futuristic and interactive **Web Security Testing Lab** built using pure HTML, CSS, and JavaScript.

This project demonstrates common cybersecurity concepts, OWASP Top 10 risks, and client-side security analysis tools in a modern hacker-style UI.

---

## 🚀 Features

### 🔍 Security Analysis Tools
- XSS Payload Detector
- SQL Injection Pattern Scanner
- Password Strength Auditor
- HTTP Security Header Checker
- Phishing URL Detector
- Encoding / Decoding Utility

### 🛡️ OWASP Top 10 Section
Interactive cards explaining:
- Broken Access Control
- Injection
- SSRF
- Cryptographic Failures
- Security Misconfiguration
- And more...

### 🎨 UI Highlights
- Cyberpunk / futuristic design
- Animated grid background
- Smooth transitions & hover effects
- Responsive layout
- Terminal-style outputs

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- Vanilla JavaScript

```bash
web-security-testing.html
```

## ⚙️ How to Run

1. Download or clone the repository
2. Open `web-security-testing.html` in your browser

```bash
git clone <your-repository-link>
```

No installation or dependencies required.
